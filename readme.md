Описание функциональности
Требуется синхронизировать список идентификаторов получаемый из HTTP API и хранящиеся в PotgreSQL
Модуль обращается в API по расписанию, указанному в конфигурационном файле, разбирает ответ, сравнивает полученные данные с тем, что хранится в БД, и добавляет/удаляет требуемые строки.
В PostgreSQL имеется следующая таблица
```
create table location_data
(
  id serial not null primary key,
  --
  lac integer,
  cellid integer,
  eci integer,
  note varchar(200),
  --
  check ( (lac is not null and eci is null) or (lac is null and cellid is null and eci is not null) )
);
```
API имеет Basic авторизацию. URL/логин/пароль, с которыми модуль будет обращаться к нему, указываются в конфигурационном файле
Модуль выполняет GET запрос по указанному URL
API отвечает следующими данными
```
HTTP/1.0 200 OK
Server: BaseHTTP/0.6 Python/3.10.12
Date: Mon, 10 Feb 2025 10:36:47 GMT
Content-type: application/json
[{"eci":null,"lac":5000,"cellid":7820},{"eci":651212,"lac":null,"cellid":null}]
```
Запрос возвращает от 1 до 50000 записей Имеются следующие ограничения на данные:
1. Допустимые сочетания параметров:
lac lac+cellid eci
2. Допустимые значения:
0 < lac < 0xFFFF
0 < cellid < 0xFFFF 0 < eci < 0xFFFFFFF
Некорректые строки должны быть проигнорированы.
Количество insert/delete для каждой синхронизации должно быть минимальным, т.е. не допускается удалить все данные из таблицы и вставить заново


Нефункциональные требования Библиотеки

HTTP - aiohttp
Асинхронная работа - asyncio
PostgreSQL - любая асинхронная библиотека
Конфигурирование

Конфигурация модуля должна храниться в файле
Должен быть предоставлен пример конфигурации
Путь к файлу конфигурации должен быть передан в модуль как параметр командной строки
Логирование
Логирование должно производиться на stdout Каждая запись должна иметь следующий формат
2025-01-17 11:58:31.811 INFO Some message
Должно быть залогировано каждое добавления или удаления строки из таблицы Должен быть залогирован факт обращения к API
